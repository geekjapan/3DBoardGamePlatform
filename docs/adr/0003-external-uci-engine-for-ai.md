# ADR 0003: AI 対戦は外部 UCI エンジン(Stockfish)に委譲する

## Status

Accepted (2026-08-11)

## Context

AI 対戦相手の実現方法として、(a) GDScript で α-β 探索を自作、(b) 外部エンジン(Stockfish)を UCI プロトコルで接続、の2案があった。当初は Web 書き出し(外部プロセス起動不可)を想定して (a) を検討していたが、対象プラットフォームが Mac + Windows デスクトップに確定したことで制約が消えた。

## Decision

Stockfish を別プロセスとして起動し、UCI プロトコル(標準入出力)で接続する。探索アルゴリズムは自作しない。強さは UCI の `Skill Level` オプションで弱/中/強の3プリセットを提供する。

エンジンバイナリはリポジトリに同梱せず、ユーザーが別途インストール(`brew install stockfish` 等)し、設定でパスを指定する。エンジンが見つからない場合は AI 対戦を無効化し、2人対戦は通常どおり遊べる。

## Consequences

- 探索・評価関数の実装とチューニングが不要になり、実装量が大幅に減る
- 強さは自作探索より遥かに上で、強さ調整も UCI オプション1行で済む
- Web 書き出しは不可能になる(外部プロセスを起動できないため)
- 実行にエンジンバイナリのインストールという前提条件が加わる
- 将棋(Phase 7)では USI プロトコルの別エンジンが必要になる。UCI アダプタは将棋を見据えたインターフェースにしておく
