# ADR 0002: キャラクターモデルの正規形式を VRM とする

## Status

Accepted (2026-08-11)

## Context

Character の 3D モデルには、オリジナル、フリー、利用許諾を得たローカルモデルなどを使えるようにする。モデルごとにリグ(ボーン構造)がばらばらだと、駒の共通アニメーション(待機・移動・駒取り)をキャラごとに作り直すことになり、キャラを増やすコストが線形に膨らむ。

公開リポジトリでは、モデル本体・テクスチャ・モーションを一切配布しない。モデルは開発者がローカルで用意する入力であり、各モデルの利用条件を満たす責任はその開発者にある。

## Decision

VRM をキャラクターモデルの正規形式とする。godot-vrm アドオンでロードし、VRM の humanoid 標準ボーンに対してアニメーションをリターゲットする。PMX など他形式は Blender(mmd_tools + VRM アドオン)で VRM に変換してからローカルへ投入する。変換手順と配布境界は `docs/model-import.md` に記録する。

## Consequences

- 共通アニメーションセット1式を全キャラで使い回せる。キャラ追加コストがほぼ「変換作業のみ」になる
- モデル投入前に Blender での変換作業という手作業が1回発生する
- godot-vrm アドオンへの依存が生じる
- ソースコードと設定は公開できる一方、モデルを含むアセットはローカル専用のままとする
- モデルを使う開発者は、入手元の利用条件・必要な表示・変換可否を個別に確認する
- プレースホルダのプリミティブ・素の glTF も引き続き装着できる(モデルスロットは形式を問わない)
