# ADR 0002: キャラクターモデルの正規形式を VRM とする

## Status

Accepted (2026-08-11)

## Context

Character の 3D モデルとして、ちび・アニメ風のオリジナル/フリーモデルに加え、原神・ゼンゼロ・NTE などが配布するモデル(多くは PMX 形式)を使いたいという要求がある。モデルごとにリグ(ボーン構造)がばらばらだと、駒の共通アニメーション(待機・移動・駒取り)をキャラごとに作り直すことになり、キャラを増やすコストが線形に膨らむ。

## Decision

VRM をキャラクターモデルの正規形式とする。godot-vrm アドオンでロードし、VRM の humanoid 標準ボーンに対してアニメーションをリターゲットする。PMX など他形式は Blender(mmd_tools + VRM アドオン)で VRM に変換してから投入する。変換手順は `docs/model-import.md` に記録する。

## Consequences

- 共通アニメーションセット1式を全キャラで使い回せる。キャラ追加コストがほぼ「変換作業のみ」になる
- モデル投入前に Blender での変換作業という手作業が1回発生する
- godot-vrm アドオンへの依存が生じる
- 配布モデルのライセンス上、本プロジェクトの成果物は個人利用に限定される。配布・公開は行わない
- プレースホルダのプリミティブ・素の glTF も引き続き装着できる(モデルスロットは形式を問わない)
